# Decisions

- Architecture: modular Next.js monolith.
- Language: strict TypeScript.
- Database and authentication: Supabase PostgreSQL/Auth.
- Styling: Tailwind CSS.
- Validation: Zod.
- Unit/integration testing: Vitest.
- Browser testing: Playwright.
- Money representation: integer minor units.
- No external paid service, production secret rotation, DNS change, or real customer messaging until separately authorized.
